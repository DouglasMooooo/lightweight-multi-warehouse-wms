# Internationalisation

Supported locales are `en` and `zh-CN`. Messages live in `i18n/messages`, and operator components request semantic keys through `useI18n()`:

```tsx
t("nav.inventory")
```

The provider stores only `wms-ui-locale` in localStorage and updates the document language. Routes remain `/inventory`, `/outbound`, and so on.

Domain and database values remain English stable codes. For example, PostgreSQL and API payloads retain `Pending_Allocation`, while the UI displays `Needs Allocation` or `待分配库位`. SKU, SN, SH, Pickup Code, warehouse codes, location codes and required ERP source values are never translated.

Status, error and action translations are presentation mappings. Unknown keys render visibly as `⟦key⟧` outside production to prevent silent translation gaps.

Warehouse terminology favors operator language: 当前库存, 出库管理, 坏机退回, 维修良品, 移库, 库存调整, 仓库调拨, 库存盘点 and 库存对账.
